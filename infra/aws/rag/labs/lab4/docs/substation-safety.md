# Substation safety rules (internal, rev 7)

Transformer fire or smoke: do not open the cabinet. Evacuate the bay, call the control room,
and wait for the transformer to be isolated and earthed by an authorised person.

Lockout-tagout (LOTO) is mandatory before any work on switchgear: isolate, lock, tag, test for dead.
Only holders of a valid authorisation card category B or higher may apply LOTO on 110 kV equipment.
