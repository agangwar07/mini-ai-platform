# Grid frequency response procedure (internal, rev 2)

Nominal grid frequency is 50.0 Hz.

- Below 49.8 Hz: activate spinning reserve within 30 seconds.
- Below 49.5 Hz: start the fast-start gas units; target full output within 10 minutes.
- Below 49.0 Hz: automatic under-frequency load shedding stage 1 operates (no operator action).

All frequency events below 49.8 Hz must be logged in the control-room event log within 15 minutes.
